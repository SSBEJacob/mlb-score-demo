# MLB Score Demo

A small React + Express app that fetches live MLB scores from `statsapi.mlb.com` and displays them in a simple scoreboard.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app locally:
   ```bash
   npm run dev
   ```

3. Open the frontend at `http://localhost:5173`.

## Production

Build and start the production server:

```bash
npm run build
npm start
```
